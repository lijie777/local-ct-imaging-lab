# Feature Specification: 联动 CT 三视图 MPR

**Feature Branch**: `004-three-view-mpr`

**Created**: 2026-07-20

**Status**: Complete

**Input**: User description: "继续执行下一个功能；采用默认或推荐方案，在现有轴位查看器基础上实现联动的轴位、冠状位和矢状位 MPR。"

## Constitutional Constraints *(mandatory)*

- **Safety notice**: 病人管理页的影像入口、轴位查看页、三视图页面、加载状态、空状态和失败状态顶部
  必须持续、清晰地显示“教学演示软件，不用于临床诊断”。三视图布局、工具栏、覆盖层和错误消息不得
  遮挡完整提示。
- **Data boundary**: 本功能仅供一名本地用户离线使用。Patient/Study/Series/Instance 元数据、DICOM
  文件、体数据和解码像素不得离开本机；所有数据请求只能访问本机服务，不得上传、同步、遥测或连接
  外部影像服务。
- **Scope boundary**: 本功能不得加入云服务、登录认证、PACS、DICOMweb、诊断报告、影像测量、标注、
  分割、三维体绘制或其他诊断能力。
- **DICOM lifecycle**: 本功能只读取 `002-dicom-import` 已持久化的可查看 CT Series、有序 Instance 和
  受管 DICOM 文件，不改变导入五类报告、数据库记录或文件内容。三视图不可用、文件缺失、解码失败或
  退出查看时不得静默跳过、删除、覆盖或修复数据。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 打开并联动浏览三个正交视图 (Priority: P1)

本地用户从已经打开的轴位 CT Series 进入三视图页面，同时看到同一 CT 数据的轴位、冠状位和矢状位。
用户在任一视图移动十字定位点或改变切片位置时，另外两个视图同步到同一个空间位置。

**Why this priority**: 从同一体数据可靠获得三个正交平面并保持空间联动，是本功能独立存在的核心价值。

**Independent Test**: 使用一套至少三张、空间信息一致且已脱敏的真实 CT Series，进入三视图后分别从
轴位、冠状位和矢状位改变定位，核对三个画面和位置提示同步，无需使用其他新增工具即可验证。

**Acceptance Scenarios**:

1. **Given** 轴位查看页已加载一个满足 MPR 条件的 CT Series，**When** 用户选择“进入三视图”，
   **Then** 系统显示同一数据的轴位、冠状位和矢状位，并默认定位到体数据中心。
2. **Given** 三个视图均已显示，**When** 用户在轴位视图移动十字定位点，**Then** 冠状位和矢状位
   同步到同一个空间位置，三个位置提示保持一致。
3. **Given** 三个视图均已显示，**When** 用户在冠状位或矢状位滚动或重新定位，**Then** 另外两个
   视图同步更新且定位不会越过体数据边界。
4. **Given** 三视图页面已打开，**When** 用户返回轴位查看器，**Then** 原 Patient/Study/Series 上下文
   仍然有效，轴位影像可以重新从默认状态浏览。

---

### User Story 2 - 识别视图并使用二维显示工具 (Priority: P2)

本地用户能清楚辨认当前活动视图、三个平面名称、病人方向和空间位置，并在三视图中使用十字定位、
窗宽窗位、平移、缩放、十字线显隐和重置。显示调整帮助教学观察，但不会修改 DICOM 数据。

**Why this priority**: 方向、位置和一致的显示控制让三视图结果可理解、可操作，同时保持在非诊断教学范围。

**Independent Test**: 在已加载的三视图中依次激活三个视图和四种主工具，验证窗宽窗位、平移、缩放、
十字线显隐和重置的可见结果，并核对覆盖层和活动状态无需依赖颜色即可理解。

**Acceptance Scenarios**:

1. **Given** 三视图已加载，**When** 用户激活任一 viewport，**Then** 系统用文字和视觉状态标识当前
   活动视图，并持续显示该视图的中文名称、病人方向和当前位置。
2. **Given** 窗宽窗位工具处于活动状态，**When** 用户在任一视图调整灰度，**Then** 三个视图使用
   一致的窗宽窗位，定位点和原始数据不变。
3. **Given** 用户选择平移或缩放，**When** 用户操作一个视图，**Then** 只有该视图的相机位置或比例
   改变，其他视图的空间定位点保持同步且不继承该视图的平移或缩放。
4. **Given** 十字定位线可见，**When** 用户隐藏后再次显示，**Then** 三个视图一致隐藏或显示定位线，
   当前空间位置不丢失。
5. **Given** 用户已改变定位、灰度、平移、缩放和十字线可见性，**When** 用户执行重置，**Then** 三个
   视图恢复体数据中心、默认相机、默认灰度、可见十字线和十字定位工具。

---

### User Story 3 - 获得安全、可恢复的 MPR 不可用与失败反馈 (Priority: P3)

本地用户在 Series 空间范围不足、文件缺失、影像无法解码、体数据构建失败或本机服务不可连接时，
能看到稳定、可理解且不泄露内部信息的反馈，并可重试或返回仍可使用的轴位查看器。

**Why this priority**: 三视图需要比单轴位更完整的空间数据和更多本机资源；明确失败边界可避免把不完整
结果误认为可用影像，也可保证故障不会破坏既有数据或轴位能力。

**Independent Test**: 分别使用单切片/重复位置 Series、暂时移除受管文件并停止本机服务，核对 MPR
入口状态、错误类别、重试/返回、轴位降级和无路径/内部 ID/技术堆栈泄露。

**Acceptance Scenarios**:

1. **Given** Series 只有一张切片或没有两个不同空间位置，**When** 轴位页加载完成，**Then** 三视图
   入口不可用并显示“至少需要两个不同空间位置的切片”，轴位查看保持可用。
2. **Given** MPR 加载过程中一个受管 DICOM 文件缺失，**When** 系统请求该影像，**Then** 页面明确
   提示本机文件缺失，提供重试和返回轴位查看器，不显示文件路径且不修改实例索引。
3. **Given** DICOM 文件存在但当前版本无法构建体数据，**When** 加载失败，**Then** 页面显示无法构建
   三视图的安全说明，不显示 codec 堆栈或内部异常。
4. **Given** 本机服务不可连接或 Series 状态已变化，**When** 用户进入或重试三视图，**Then** 系统显示
   对应的本机服务或不可查看反馈，用户可以重试或返回轴位查看器。
5. **Given** 三视图仍在加载，**When** 用户返回轴位查看器，**Then** 未完成请求和页面资源被取消或
   释放，不产生离开页面后的错误或状态更新。

### End-to-End Acceptance Path *(mandatory)*

1. 启动只绑定本机地址并使用全新独立临时数据目录的应用。
2. 创建一位虚构病人，导入一套至少三张、已脱敏且空间信息一致的真实 CT DICOM Series。
3. 从 Patient → Study → Series 打开轴位查看器，确认轴位图像和非临床提示正常。
4. 选择“进入三视图”，核对轴位、冠状位、矢状位均显示非黑影像，摘要和元数据不泄露内部信息。
5. 在轴位、冠状位和矢状位分别移动十字定位或滚动，核对另外两个视图及位置提示同步。
6. 依次验证活动视图、窗宽窗位同步、平移、缩放、十字线显隐和重置。
7. 返回轴位页并再次进入三视图，确认上次定位和显示状态未被恢复。
8. 使用空间范围不足的 Series，确认三视图入口被阻止而轴位查看仍可使用。
9. 模拟受管文件缺失、本机服务失败和加载中退出，核对安全错误、重试、返回和资源清理。
10. 检查键盘操作、完整非临床提示、浏览器 Console 和只访问本机服务的 Network 请求。
11. 重启前后端后重新打开同一病人与 Series，确认持久化数据仍可构建相同三视图。

### Edge Cases

- Series 只有一张切片、多个 Instance 位于同一空间位置或切片法向空间范围为零时，轴位可以查看但
  MPR 入口必须禁用。
- Series 在轴位页显示为 eligible、进入 MPR 前已被删除或改为 unsupported 时，必须重新校验并失败。
- 三个 viewport 宽高在初次加载或窗口调整时为零或极小时，恢复可用尺寸后必须正确 resize 和 render。
- 快速连续滚动、拖动十字定位或切换工具时，最终位置不得越过体数据边界，较早异步结果不得覆盖
  较新的用户操作。
- 某张切片加载失败时不得自动删除、跳过或改写该实例；当前 MPR session 可失败并允许重试或返回轴位。
- 用户隐藏十字线时，当前定位点必须保留；重新显示后十字线回到该位置。
- 窄屏布局改为纵向排列时，三个 viewport、元数据、工具栏和安全提示仍可到达且不互相遮挡。
- 用户仅使用键盘时，必须能够操作返回、重试、工具、十字线显隐、重置和聚焦三个 viewport。
- 用户在 volume 创建、像素加载或同步器初始化完成前退出时，未完成请求和所有已创建资源必须释放。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 从已加载的轴位查看页为满足 MPR 条件的 CT Series 提供“进入三视图”入口。
- **FR-002**: 系统 MUST 在 MPR 不可用时保留轴位查看能力，并显示稳定、可理解的不可用原因。
- **FR-003**: 系统 MUST 只允许至少包含两个不同空间位置、尺寸和方向一致且像素可用的 CT Series
  进入 MPR。
- **FR-004**: 系统 MUST 使用同一 CT 数据同时显示轴位、冠状位和矢状位三个正交视图，不得为每个
  视图创建彼此无关的数据副本。
- **FR-005**: 三视图首次显示时 MUST 定位到体数据中心，并 MUST 在三个视图中表达同一个空间位置。
- **FR-006**: 每个 viewport MUST 持续显示中文视图名称、病人方向和当前空间位置。
- **FR-007**: 系统 MUST 使用文字和视觉状态共同标识当前活动 viewport，不得只通过颜色表达。
- **FR-008**: 用户 MUST 能够在任一 viewport 移动十字定位点，并使另外两个 viewport 同步到同一
  空间位置。
- **FR-009**: 用户 MUST 能够在任一 viewport 通过滚轮改变切片位置，且另外两个 viewport 的定位
  必须同步。
- **FR-010**: 系统 MUST 阻止定位或切片导航越过体数据空间边界。
- **FR-011**: 用户 MUST 能够选择十字定位、窗宽窗位、平移或缩放作为当前主鼠标工具。
- **FR-012**: 系统 MUST 保证任一时刻只有一个主鼠标工具处于活动状态，并清晰显示当前工具。
- **FR-013**: 任一 viewport 的窗宽窗位变化 MUST 同步到另外两个 viewport。
- **FR-014**: 平移和缩放 MUST 只改变被操作 viewport 的相机，不得改变其他 viewport 的平移和缩放。
- **FR-015**: 用户 MUST 能够一致隐藏或显示三个 viewport 的十字定位线，显隐不得丢失定位点。
- **FR-016**: 用户 MUST 能够重置三视图；重置 MUST 恢复体数据中心、三个默认相机、默认灰度、
  可见十字定位线和十字定位工具。
- **FR-017**: 用户 MUST 能够返回同一 Patient/Study/Series 的轴位查看页，轴位页 MUST 继续可用。
- **FR-018**: 系统 MUST NOT 持久化 MPR 定位、活动 viewport、工具、十字线、窗宽窗位、平移或缩放；
  重新进入时必须使用默认状态。
- **FR-019**: 三视图页面 MUST 显示 Patient 姓名/病历号、Study 描述/日期、Series 描述、Modality、
  Rows、Columns、实例数量和可推导时的相邻切片间距。
- **FR-020**: 用户界面 MUST NOT 显示内部资源 ID、DICOM UID、绝对路径、原始文件名或技术堆栈。
- **FR-021**: 系统 MUST 区分 MPR 条件不足、Series 不可查看、文件缺失、无法解码/构建、本机服务失败
  和通用本机渲染失败，并提供稳定、可理解的反馈。
- **FR-022**: 所有三视图失败状态 MUST 提供返回轴位查看器；可恢复的加载失败还 MUST 提供重试。
- **FR-023**: 三视图失败 MUST NOT 自动跳过、删除、覆盖、修复或修改既有 Instance 索引和受管文件。
- **FR-024**: 页面卸载、返回轴位页、Series 变化、重试或加载取消时，系统 MUST 停止未完成加载、
  释放该页面创建的体数据、视图、工具和同步资源，并停止离开页面后的状态更新。
- **FR-025**: 三视图 MUST 在桌面使用包含三个 viewport 和一个元数据面板的二乘二布局，并在窄屏
  转为可完整访问的纵向布局。
- **FR-026**: 返回、重试、工具、十字线显隐、重置和三个 viewport MUST 具有可理解的文字名称并可
  通过键盘到达；当前工具、活动 viewport、位置和错误不得只通过画布像素或颜色表达。
- **FR-027**: 轴位页、三视图页、加载、空和失败状态 MUST 持续、清晰显示完整“教学演示软件，
  不用于临床诊断”提示。
- **FR-028**: 所有 Patient/Study/Series/Instance 元数据、DICOM 文件、体数据和像素 MUST 保留在本机；
  本功能发出的网络请求 MUST 仅访问本机服务。
- **FR-029**: 系统 MUST 只显示三个二维正交 viewport，不得加入三维 viewport、体绘制或诊断能力。

### Non-Goals *(mandatory)*

- 不实现长度、角度、面积、密度等测量，不实现标注、分割、截图报告或诊断报告。
- 不实现三维体绘制、表面重建、最大密度投影或手术规划。
- 不实现 PACS、DICOMweb、远程 URL 加载、云存储、遥测、账户、登录或权限。
- 不实现 MPR 状态持久化、书签、最近查看列表或深链接。
- 不修改 DICOM 导入分类、实例排序、受管文件内容、数据库结构或病人删除生命周期。
- 不移除或替换已完成的单轴位查看能力。

### Key Entities *(include if feature involves data)*

- **MPR Eligibility**: 当前 Series 是否具备至少两个不同空间位置以及一致尺寸、方向和像素条件；只在
  当前加载会话计算，不写回数据库。
- **MPR Volume**: 当前会话从一个有序 CT Series 构建的本机体数据；供三个正交视图共享，退出即释放。
- **MPR Viewport**: 轴位、冠状位或矢状位中的一个二维视图；具有方向、相机、当前空间位置和活动状态。
- **Linked Position**: 三个 viewport 共享的世界坐标定位点；十字定位和切片导航均更新此位置。
- **MPR Session**: 从进入三视图到返回轴位页之间的临时工具、定位、灰度、相机和可见性状态；不持久化。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对满足条件的 Series，用户可从已加载轴位页通过 1 次可见操作进入三视图。
- **SC-002**: 在验收机器和至少三张真实 CT 切片上，轴位、冠状位和矢状位均在 8 秒内显示非黑影像。
- **SC-003**: 在三个 viewport 分别改变定位的全部验收操作中，另外两个 viewport 100% 同步到同一
  空间位置，且没有越界。
- **SC-004**: 窗宽窗位、平移、缩放、十字线显隐和重置五类操作在真实浏览器中均产生可观察且符合
  说明的结果。
- **SC-005**: MPR 条件不足、文件缺失、无法解码/构建和服务失败四类验收场景均提供可理解反馈、
  返回能力和适用的重试，用户可见内容中不存在路径、内部 ID 或技术堆栈。
- **SC-006**: 返回并重新进入同一 Series 的全部验收中，定位、活动视图、工具、十字线、灰度、平移和
  缩放均恢复默认状态。
- **SC-007**: 加载中退出的全部验收中，离开页面后没有继续的影像请求、遗留三视图画布或控制台错误。
- **SC-008**: 桌面和窄屏验收中，三个 viewport、元数据、工具和完整非临床提示均可见或可滚动到达，
  关键操作 100% 可通过键盘完成。
- **SC-009**: 真实浏览器验收期间 100% 影像和元数据请求只访问本机地址，重启服务后同一持久化
  Series 仍可重新构建三视图。
- **SC-010**: 适用的后端、前端自动化测试、production build 和完整真实浏览器验收路径全部通过后，
  本功能才视为完成。

## Assumptions

- 一名本地用户在桌面浏览器中操作，输入数据为已脱敏的教学 CT DICOM。
- `001`、`002` 和 `003` 已分别提供 Patient 管理、DICOM 持久化与有序 Instance、单轴位查看和安全文件资源。
- MPR 默认从体数据中心开始，十字定位线默认可见，十字定位是默认主工具。
- 窗宽窗位在三视图间共享；平移和缩放按 viewport 独立；这是用户未指定时的推荐默认。
- MPR eligibility 在当前 Series 加载会话中计算，不新增数据库状态；失败不改变轴位可查看状态。
- 页面刷新回到病人管理页，三视图状态不需要跨刷新或服务重启恢复。
- 本功能不依赖任何外部服务，也不需要修改既有持久化数据模型或受管文件。
