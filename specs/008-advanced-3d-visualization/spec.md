# Feature Specification: 高级 3D 可视化

**Feature Branch**: `008-advanced-3d-visualization`

**Created**: 2026-07-23

**Status**: Complete

**Input**: User description: "增加 3D 体绘制、表面重建和 MIP 功能"

## Constitutional Constraints *(mandatory)*

- **Safety notice**: 轴位入口页和高级 3D 页必须持续显示“教学演示软件，不用于临床诊断”或语义等价提示；
  加载、成功、失败、窄屏和重试状态都不得遮挡该提示。
- **Data boundary**: Series 元数据、DICOM 像素、三维场景和表面数据必须保留在本机；不得上传、同步、
  遥测或访问外部服务。
- **Scope boundary**: 本 Feature 不加入认证、云、PACS、DICOMweb、诊断报告、分割、手术规划、网格导出、
  3D 测量或查看器状态持久化。
- **DICOM lifecycle**: 本 Feature 只读现有受管 DICOM，不改变导入五类报告、数据库记录、文件顺序或删除语义；
  任一加载或重建失败都不得修改持久化数据。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 查看可交互体绘制 (Priority: P1)

教学用户从可查看的 CT Series 进入高级 3D，看到完整体数据的三维体绘制，并可旋转、平移、缩放、
切换骨、软组织和肺三个显示预设。

**Why this priority**: 体绘制是高级三维功能的基础价值，并建立 MIP 和表面重建共用的加载、相机与安全边界。

**Independent Test**: 使用一个满足空间条件的本机 CT Series 进入高级 3D；无需使用其他两种模式即可验证
非黑体绘制、三个预设、相机交互、重置、返回和重新进入默认状态。

**Acceptance Scenarios**:

1. **Given** 一个可查看且具有至少两个不同空间位置的 CT Series，**When** 用户从轴位页进入高级 3D，
   **Then** 页面在持续显示非临床提示的同时显示非黑体绘制、Series 摘要和当前“体绘制”状态。
2. **Given** 体绘制已显示，**When** 用户切换骨、软组织或肺预设，**Then** 同一体数据的显示外观改变，
   无需重新选择 Series 或重新进入页面。
3. **Given** 用户已旋转、平移或缩放场景，**When** 用户执行重置，**Then** 场景恢复默认前方视角、
   默认骨预设和完整体数据范围。
4. **Given** 用户返回轴位页后再次进入，**When** 新的高级 3D 会话准备完成，**Then** 不恢复上次会话状态，
   而是使用完整的默认体绘制状态。

---

### User Story 2 - 使用最大强度投影 (Priority: P2)

教学用户切换到 MIP，观察体数据沿不同方向的最大强度投影，并调整投影厚度以比较完整体数据与局部 slab。

**Why this priority**: MIP 为高密度结构提供与体绘制不同的教学观察方式，同时复用已加载体数据。

**Independent Test**: 在已经完成 P1 加载的 Series 中切换到 MIP，单独验证六个标准方向、自由旋转、厚度范围、
重置和切回体绘制，不依赖表面重建。

**Acceptance Scenarios**:

1. **Given** 高级 3D 已准备完成，**When** 用户选择 MIP，**Then** 页面显示最大强度投影并明确标识当前模式。
2. **Given** MIP 已显示，**When** 用户选择前方、后方、左侧、右侧、头侧或足侧，**Then** 投影切换到
   相应标准观察方向，且用户仍可自由旋转。
3. **Given** MIP 已显示，**When** 用户减小或增大投影厚度，**Then** 投影使用新的毫米厚度，取值始终位于
   当前体数据允许范围内。
4. **Given** 用户从 MIP 切回体绘制，**When** 体绘制重新显示，**Then** 恢复用户上次选择的体绘制预设，
   不把 MIP 显示设置带入体绘制。

---

### User Story 3 - 按阈值重建真实表面 (Priority: P3)

教学用户切换到表面模式，以默认或自定义 HU 阈值从 CT 体数据生成真实三角表面，比较不同阈值产生的结构。

**Why this priority**: 表面重建提供区别于体绘制和投影的几何观察能力，但计算成本和失败边界更高，应在共享
体数据和基础交互稳定后实现。

**Independent Test**: 对已加载 CT 使用默认 300 HU 和另一个有效阈值生成两个不同表面，再使用不产生几何的
阈值验证空结果和恢复；无需依赖 MIP。

**Acceptance Scenarios**:

1. **Given** CT 强度范围包含 300 HU，**When** 用户首次进入表面模式，**Then** 系统准备并显示 300 HU
   默认阈值；用户执行“应用阈值”后生成真实几何表面。
2. **Given** 用户输入位于实际 scalar 范围内的新阈值，**When** 用户应用阈值，**Then** 页面显示重建状态，
   完成后用新表面替换旧表面。
3. **Given** 当前 CT 体积超过安全表面处理上限，**When** 用户重建表面，**Then** 系统自动降低采样密度，
   保持体数据的物理尺寸和方向，并向用户说明该处理。
4. **Given** 某个阈值没有生成任何三角形，**When** 重建结束，**Then** 页面显示“该阈值未生成可见表面”
   或语义等价消息，并允许用户修改阈值后重试。
5. **Given** 表面计算失败，**When** 用户切换回体绘制或 MIP，**Then** 已加载体数据仍可使用，失败不要求
   重新进入 Series，也不泄露路径、UID、像素内容或堆栈。

### End-to-End Acceptance Path *(mandatory)*

1. 在独立本机数据目录创建虚构病人并导入已脱敏、满足空间条件的 CT Series。
2. 从病人管理进入轴位查看器，确认非临床提示和“进入高级 3D”入口可见。
3. 进入高级 3D，确认默认骨预设体绘制、元数据、相机交互和重置。
4. 依次切换软组织与肺预设；进入 MIP，验证六方向、自由旋转和至少两个投影厚度。
5. 进入表面模式，以 300 HU 和第二个阈值生成两个可见表面，再验证一个空表面阈值。
6. 验证表面失败不影响体绘制/MIP；验证文件缺失和本机服务停止的安全错误与恢复。
7. 在桌面和窄屏尺寸验证 SafetyBanner、控制区、viewport、元数据、键盘焦点和返回操作。
8. 连续三次进入/退出，再重启本机服务并重新进入；确认每次使用默认状态且无资源累积导致的失败。
9. 记录首个 3D 画面时间、表面时间、Console、Network 和截图；Network 必须完全限制在本机。

### Edge Cases

- Series 在进入前已删除、变为不可查看、几何信息不足或只有一个空间位置。
- DICOM 文件缺失、解码失败、volume 只有部分 frame 完成或浏览器不支持所需图形能力。
- CT 强度数据为空、包含无效值、实际范围不包含 300 HU，或用户输入超出实际范围。
- 表面阈值位于数据极端并产生零三角形或过大的三角形数量。
- 用户在加载、表面重建、模式切换、重试或返回过程中快速连续操作。
- 大体积需要降低表面采样密度，或浏览器因内存不足拒绝重建。
- 页面反复进入退出、窄屏重排、浏览器刷新或本机服务重启。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统必须只为满足现有多位置 CT 空间条件的 Series 提供高级 3D 入口；不满足条件时必须保持
  轴位查看可用并说明原因。
- **FR-002**: 系统必须在进入高级 3D 时重新校验当前 Series，不能仅依赖轴位页中的旧状态。
- **FR-003**: 高级 3D 页必须持续显示非临床提示、可见返回操作和不含内部标识的 Patient/Study/Series 摘要。
- **FR-004**: 三种模式必须共享同一次 Series 数据准备结果；模式切换不得重新下载相同 DICOM Series。
- **FR-005**: 默认模式必须为体绘制，默认显示预设必须为骨，并支持骨、软组织、肺三个具名预设。
- **FR-006**: 体绘制必须支持旋转、平移、缩放和恢复默认相机、显示预设及完整体范围。
- **FR-007**: MIP 必须使用最大强度投影，支持前方、后方、左侧、右侧、头侧、足侧六个标准方向和自由旋转。
- **FR-008**: MIP 投影厚度必须以毫米表达，范围必须根据当前体数据物理尺寸计算，默认覆盖完整体数据。
- **FR-009**: 从 MIP 返回体绘制时必须恢复用户最后选择的体绘制预设。
- **FR-010**: 表面模式必须从实际 CT 强度数据生成真实几何表面，不得用调整体绘制透明度冒充表面重建。
- **FR-011**: 表面阈值必须限制在当前 CT 强度范围内；默认值为 300 HU，范围不包含 300 时取范围中点。
- **FR-012**: 表面重建必须由明确的“应用阈值”操作触发，并在计算期间提供可感知状态、阻止冲突操作。
- **FR-013**: 超过安全表面处理上限的体数据必须自动降低采样密度，保持物理尺寸、世界方向和原始体数据
  不变，并向用户说明。
- **FR-014**: 新阈值成功后必须替换旧表面；零三角形必须作为可恢复空结果处理，而不是通用崩溃。
- **FR-015**: 表面失败必须与共享体数据隔离，用户仍能切换到体绘制或 MIP。
- **FR-016**: 页面退出、失败和重试必须释放本次会话的请求、体数据、表面、交互工具、事件和图形资源；
  过期异步结果不得更新新会话。
- **FR-017**: 高级 3D 状态不得持久化；每次重新进入必须恢复默认体绘制状态。
- **FR-018**: 所有控件必须有非颜色状态、键盘可操作名称和清晰焦点；加载/重建状态必须可被辅助技术感知。
- **FR-019**: 桌面和窄屏布局都必须保持非临床提示、返回、模式、viewport 和错误信息可见且不互相遮挡。
- **FR-020**: 所有错误必须使用用户安全中文消息，不得显示绝对路径、内部 UUID、DICOM UID、像素内容、
  codec 细节或堆栈。
- **FR-021**: 本 Feature 必须只读现有 Series/Instance/受管文件，不得修改数据库、文件或导入报告。
- **FR-022**: 所有网络访问必须保持本机同源，不得产生外部请求、遥测或云依赖。

### Non-Goals *(mandatory)*

- 分割、轮廓编辑、手工修面、表面平滑参数和网格导出。
- 3D 测量、标注、裁剪、融合、多 Series 配准、诊断和手术规划。
- 保存 3D 模式、相机、preset、MIP 厚度或表面阈值。
- 后端表面任务、网格缓存、新数据库表或新远程 API。
- 云服务、账户、认证、PACS、DICOMweb、遥测和诊断报告。

### Key Entities *(include if feature involves data)*

- **Advanced 3D Session**: 当前 Series 的临时只读会话；包含模式、相机、体绘制预设、MIP 厚度、
  标准方向、表面阈值和运行状态，退出后销毁。
- **Shared CT Volume**: 由当前 Series 全部实例形成的体数据；包含物理尺寸、空间方向、CT 强度范围和准备进度。
- **Surface Reconstruction**: 某个阈值对应的临时三角表面；包含阈值、采样步长、结果状态和可见 mesh，
  不写入文件或数据库。

## Assumptions

- 现有 MPR eligibility 是高级 3D 的最低空间条件，当前 Feature 不建立第二套几何资格规则。
- 现代本机浏览器支持本功能所需的三维图形能力；不满足能力时显示安全不可用消息。
- CT 强度值已应用 DICOM rescale，可用 HU 表达阈值；若输入数据无法提供有限强度范围，则
  表面模式不可用，但体绘制和 MIP 仍可继续。
- 表面重建只承诺教学可视化质量；自动降低采样密度允许几何细节减少，但不得改变物理范围和方向。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对验收 CT，从进入高级 3D 到首个非黑体绘制在 10 秒内完成。
- **SC-002**: 体数据准备完成后，体绘制与 MIP 之间的模式切换在 2 秒内提供可见结果，且不重新下载 Series。
- **SC-003**: 对标准的已脱敏多切片验收 CT，每次表面重建在 15 秒内完成或返回明确可恢复错误。
- **SC-004**: 用户可在一次会话中完成三个体绘制预设、六个 MIP 方向、两个 MIP 厚度和两个表面阈值的操作，
  无需刷新或重新进入 Series。
- **SC-005**: 桌面 1280×900 与窄屏 820×900 下，100% 的主要控件、非临床提示、viewport 和返回操作可见、
  可通过键盘到达且不被遮挡。
- **SC-006**: 连续三次进入/退出以及本机服务重启后，功能仍可重新进入并恢复默认状态，无资源累积导致的失败。
- **SC-007**: 文件缺失、服务停止、空表面和表面计算失败四类场景均提供安全、可恢复的用户反馈，且不修改
  现有持久化数据。
- **SC-008**: 真实验收期间 100% 网络请求保持 loopback，同一成功路径无未处理 Console error。
